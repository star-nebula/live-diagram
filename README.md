## Core ideas

Rewritten from the *method* of [ythx-101/live-panel-skill](https://github.com/ythx-101/live-panel-skill) — every line of code here is an independent implementation:

- **The layout never moves; what moves is system state.** Any single frame is a complete, readable diagram.
- **Deterministic rendering.** The page exposes `window.seek(t)`; every visible change is a pure function of `t` (no wall clock, no `Math.random`, no CSS animation) → frames are reproducible and verifiable.
- **One truth everywhere.** Log lines are generated by the same state machines that drive the boxes — the number in the log is the number on the bar, by construction.
- **No real data? Say "illustrative."** Never present a made-up measurement as real; credit others when recreating their work.

## Usage

Requirements: Python 3.8+ (standard library only), Chrome/Chromium/Edge, ffmpeg. Windows / macOS / Linux.

```bash
# Render mp4 (--html-out also keeps a live web page)
python scripts/livediagram.py render --config my.json --out my.mp4 --html-out my.html --crf 10 --preset slow

# Layout audit (~120 sampled moments, DOM measurements) + PNG exports + byte-identical replay proof
python scripts/livediagram.py check --config my.json --out-dir frames --repeat

# Web page only (opens live in any browser; append ?t=SECONDS to freeze a frame)
python scripts/livediagram.py build --config my.json --out page.html
```

As an AI skill: drop this folder into your agent's skills directory (e.g. `~/.zcode/skills/`, `~/.claude/skills/`) and SKILL.md is picked up automatically.
